# Project Notes

## Mission

**S-IDE** is a focused browser IDE for opening a local workspace, editing files, and running common developer commands from a clean, single-window interface.

## Highlights

- **Zero Runtime Dependencies**: The entire client and preview server run without third-party npm packages.
- **Persistent Local Workspace**: Edits are preserved across browser sessions via `localStorage`.
- **Responsive Layout**: Adapts gracefully across desktop, tablet, and mobile viewports.
- **Extensible Shell**: Activity rail supports Explorer, Search, Source Control, Run & Debug, and Extensions views.

For full architectural breakdown, see [`docs/ARCHITECTURE.md`](ARCHITECTURE.md).
